# ATM Simulator System

ATM Simulator System is a Java-based desktop application that simulates the
basic operations of an Automated Teller Machine (ATM).

The application is developed using Java Swing for the graphical user interface
and MySQL for database management. JDBC is used to establish communication
between the Java application and the MySQL database.

## Features

- User account registration
- Card number and PIN-based login
- Deposit money
- Cash withdrawal
- Fast cash withdrawal
- Balance enquiry
- Mini statement
- PIN change
- Transaction management
- MySQL database integration
- Interactive Java Swing GUI

## Technologies Used

- Java
- Java Swing
- JDBC
- MySQL
- NetBeans

## Project Structure

The project contains separate Java classes for:

- Login and authentication
- User registration
- Transactions
- Deposit
- Withdrawal
- Fast Cash
- Balance Enquiry
- Mini Statement
- PIN Change
- Database connectivity

## Database

The application uses MySQL to store user and transaction information.
JDBC is used to connect the Java application with the MySQL database.

## How to Run

1. Clone the repository.
2. Open the project in NetBeans.
3. Create the required MySQL database.
4. Configure the database connection in `Conn.java`.
5. Add the required MySQL JDBC driver.
6. Build and run the project.
7. Start with the Login/Signup screen.
